# Thesis stuff

## Structure

- `base/` - thesis source (LaTeX, KI UJEP template clone) with the pgfplots figures; see `base/FIGURES.md`
- `EN-base/` - English Markdown drafts
- `notes/` - chronological notes from the UJEP-LAB history, requirements, test plan
- `data/` - benchmark and stability data
- `dump/` - Overleaf export of the earlier Mellanox paper
- `zadani/` - moodle assignment content
- `skki/` - presentation
- `justfile` - `just` lists tasks (`thesis`, `figures`, `latex-data`, `overleaf`, `check`)
