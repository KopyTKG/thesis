# data

- `benchmark_data.json` - throughput dataset (older, see notes/13 for known problems)
- `stability_data.json`, `stability_charts.json`, `stability/*.csv` - cold-boot stability results from 2026-10-01
- Figures are made in LaTeX (pgfplots): see `../latex/`. Regenerate the CSVs the figures read with `just latex-data`.

## HPL data

`hpl_data.json` holds the HPL (LINPACK) runs of 2026-10-22 (1, 5 and 10 nodes) with the hardware/software description and findings; the CSV and the raw HPL outputs are in `hpl/`. Generated by `UJEP-LAB/tools/make_hpl_data.py` from `benchmarks/hpl`; narrative in note 17.
