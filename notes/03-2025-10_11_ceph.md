# 03 - Oct to Nov 2025: Ceph on Rocky 10

Period: 2025-10-30 to 2025-11-13. Source: `LOG.md` (later `docs/Ceph.md`), `tools/ceph.sh`, benchmark CSV.

## Setup

- 2025-10-30: all nodes reinstalled with **Rocky Linux 10.0**; HDDs cleaned of an old Ceph setup. Nodes were named `Rocky-OKD-Host-1..8` (prepared for OKD).
- **OKD rejected** the same day: needs 3 masters that cannot serve as workers, so the cluster would lose 3 of 8 nodes.
- Migration target: OpenNebula.
- Setup recipe recorded: `ib_ipoib` autoload, `/etc/hosts` for 10.0.0.0/24 plus controller `10.0.0.254`, OpenSM, chrony (CESNET NTP), `cephadm bootstrap --mon-ip 10.0.0.254` (IPoIB so Ceph could use 100 Gb/s), root SSH key distribution, `ceph orch host add`. Ceph UI on `https://controller:8443`.
- 2025-11-06: looping shell helpers added to the log, jinja2 into install script, Ceph logs backed up.

- 11-12: controller migrated to another Supermicro node (Rocky 10.0). Web UI broke after migration. Speed still capped "by something on the Ceph side". Commit `86d9199` message: "LIKE BRUH WHAT THE HELL CEPH" (405 log lines).
- 11-12: power profiles tested; 11-13 logs split per filesystem (`Ceph.md`, `BeeGFS.md`).

## Verdict

Rejected. Stable, but software overhead: ~1 GB/s at 1 replica, 0.4-0.7 GB/s at 2-3 replicas versus raw SSD ceiling. Later comparison in `docs/Lustre.md`: Lustre delivers 14-28x Ceph's throughput on the same hardware.
